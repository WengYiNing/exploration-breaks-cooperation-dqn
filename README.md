# Shared Value Representations Drive Exploration-Induced Cooperation Collapse in Spatial Social Dilemmas

This repository contains the experimental and plotting code for the paper:

**Shared Value Representations Drive Exploration-Induced Cooperation Collapse in Spatial Social Dilemmas**

## Overview

We investigate exploration-induced cooperation collapse in spatial social dilemmas using shared-policy Deep Q-Networks (DQN). The experiments examine how exploration strength, parameter sharing, state representations, learned action values, and network topology affect cooperation.

The repository provides experimental and plotting scripts for all seven main-text figures:

- **Figure 1:** Cooperation landscape of shared DQN across exploration strength (B) and payoff harshness (Dr).
- **Figure 2:** Empirical cooperation-collapse boundaries for shared and grouped DQN.
- **Figure 3:** Effects of parameter-sharing scale and replay-buffer capacity on cooperation.
- **Figure 4:** State-augmentation experiments comparing baseline, exploration-temperature, annealing-progress, and combined representations.
- **Figure 5:** Hidden-representation analysis using UMAP and silhouette scores.
- **Figure 6:** Action-value diagnostics, including Q-mean and Q-gap.
- **Figure 7:** Cooperation across grid, modular 4-regular, random 4-regular, and rewired 4-regular network topologies.

The `experiments/` directory contains simulation scripts, while the `plotting/` directory contains the corresponding figure-generation scripts.

## Experiments

Each experimental script contains the simulation parameters and random-seed settings for its corresponding figure.

Figure 3 uses the following configurations:

| Configuration | Networks | Agents per network | Replay buffer per network |
| ------------- | -------: | -----------------: | ------------------------: |
| Shared DQN    |        1 |                900 |                    90,000 |
| Grouped DQN   |       10 |                 90 |                     9,000 |
| Grouped DQN   |      100 |                  9 |                     9,000 |
| Grouped DQN   |      100 |                  9 |                       900 |

The shared-DQN configuration can be reproduced using the Figure 1 experimental script with Dr = 0.25. The remaining configurations use `fig3_experiment - grouped DQN.py`, with `NUM_GROUPS` and `REPLAY_SIZE` adjusted as indicated in the script.

Figure 4 uses a single experimental script, `fig4_experiment - state size augmentation.py`, with four available `STATE_MODE` settings:

- `baseline`: 5-dimensional state
- `tau`: 6-dimensional state with normalized exploration temperature
- `progress`: 6-dimensional state with annealing progress
- `both`: 7-dimensional state with both additional features

## Plotting Scripts and Input Files

The plotting scripts require simulation outputs generated by the corresponding experimental scripts. These outputs must be collected into the input files or directories specified near the beginning of each plotting script.

For example, to generate the Figure 1 simulation output:

```bash
python "experiments/fig1_experiment -  shared DQN.py" > figure1.txt
python plotting/fig1_plot.py
```

Note that full experimental sweeps are computationally intensive.

Input requirements vary by figure:

- **Figures 1–4 and 7:** Text files containing simulation results. Save or redirect the printed experiment outputs into the files expected by the plotting scripts.
- **Figure 5:** Saved model checkpoints and sampled state arrays generated by its experimental script.
- **Figure 6:** Individual Q-mean and Q-gap result files generated by the corresponding experimental scripts.

Figure 7's grid configuration can reuse the corresponding shared-DQN results from Figure 1 at Dr = 0.25.

The plotting scripts specify their expected input filenames and directories. Prepare these inputs before running the corresponding script.

The complete raw simulation datasets are not included in this repository due to their size. The provided scripts allow the experiments to be rerun with the specified parameters and random seeds.
